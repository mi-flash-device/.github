## Game Overview

Mi Flash writes a fastboot package to a Xiaomi phone you own, when that phone is already in the state the vendor tool expects and the package is the official image for that exact model. Flashing can erase your data and can leave the phone unusable if the package is wrong. Back up first, to a place you have restored from before. This tool does not remove a Google account lock, FRP, a carrier lock, or a forgotten lock screen.

If the phone is not yours, stop. If it asks for the previous owner's account, stop. You need that account. A forum ROM is not a substitute for the package that matches the model in your hand. Do not flash a file you cannot tie to that model from the vendor.

## Play Your Way

Prepare, and do not flash yet. Install the tool, put the official package in a folder you can name, and read the model it claims. Compare that model with the phone. Charge the phone. Copy photos and accounts off it. If you cannot afford to lose what is on the phone, do not continue.

Flash only when the backup exists and the package matches. Use a data cable. Follow the vendor's own steps for a phone you are allowed to service. When it finishes, set the phone up as the owner. If it boots to an account you do not know, you flashed a device you should not have, or the lock was already there. Mi Flash will not clear it.

## Mission Flow

Confirm the phone is yours and that you can unlock the screen today. Copy off anything you need. Unplug other phones so you cannot select the wrong one.

Select the official package for this model. Read the path twice. Start the flash only then. Wait until it finishes. Do not unplug the cable because the screen went black. That can be the write. If the tool reports a mismatch, stop and check the model. Do not try a different region's package to get past an account prompt. That prompt is not a flashing error to bypass.

## Perfect Audience

Mi Flash fits an owner who already has the vendor package for this exact phone and has a backup they can live with. The model on the box and the model in the package name should match.

It does not fit a locked phone, a phone that is not yours, a carrier restriction, or a file from a forum. If you cannot afford a wipe, do not start. If the account prompt appears, the account holder has to sign in.

## Common Issues

The phone is not seen when the cable is charge-only, the drivers for this mode are missing, or another phone is plugged in. Fix the cable. Do not look for a lock bypass. A package error means the file does not match the phone. Stop. A boot that asks for an unknown account is FRP or the previous account. This tool does not clear it. A phone that will not boot after a wrong package needs the correct official image for that model, not a third unrelated file.

## Extended Notes
